# Glossary

Short definitions of the statistical and interface terms used in RcmdrShiny
Studio. Each term links to the topic that explains it in context.

## Interface terms

### Active data set

The data frame that dialogs, menus and the inspector read. It is shown in the
top bar and in the status bar. Choosing a different data set changes the active
data set, not the data itself. See [Data Studio](topic:data-studio).

### Active model

The model that the model menus and diagnostic plots use. Fitting a model from a
dialog usually makes it active. See [Models](topic:linear-model).

### Command log

The ordered list of R commands generated by the interface. It is the
reproducibility contract: every action in a dialog produces one or more lines
in the log, and those lines can be copied into the script or a report.

### Command palette

The search box opened with `Ctrl` + `K`. It searches menus, dialogs, help
topics, data sets, variables, workflows and recent commands. See
[Command palette and workflows](topic:navigation-workflows).

### Dialog memory

The values a dialog remembers the next time it is opened. Memory is session
state, not a command, and can be cleared with **Reset**.

### Preset

A named set of dialog values saved by the user. A preset is a convenience for
filling a dialog; applying it still runs the dialog and logs the command. See
[Command palette and workflows](topic:navigation-workflows).

### Preview

The isolated evaluation of a command before it is logged. Previews never touch
the command log, the output or the plot gallery. See
[Chart Studio](topic:chart-studio).

### Workflow

A guided sequence that opens existing dialogs and records the commands they
produce. A workflow does not contain its own statistical logic.

## Statistical terms

### Coefficient

The estimated effect of one predictor in a model, usually on the scale of the
linear predictor. See [Linear model](topic:linear-model).

### Confidence interval

A range of plausible values for a parameter, computed at a stated confidence
level. The interpretation is frequentist: repeated samples would contain the
true value in the stated proportion of intervals.

### Contrast

A linear combination of factor levels used to compare groups. R uses treatment
contrasts by default; **Data > Manage variables > Set contrasts...** changes
them for a factor. See [Set contrasts](topic:setContrasts).

### Degrees of freedom

The amount of independent information available to estimate a quantity. It
appears in tests, confidence intervals and model summaries.

### Factor

An R vector with a fixed set of levels, used for categorical variables. A
character column is not automatically a factor in every dialog; use the
conversion dialogs when a procedure requires factors. See
[Converting character variables](topic:converting-character-variables).

### Missing value

`NA` in R. Most summaries report the number of missing values; many models drop
incomplete rows by default. See [Missing data](topic:troubleshooting).

### p-value

The probability, assuming the null hypothesis is true, of observing a result at
least as extreme as the one obtained. It is not the probability that the null
hypothesis is true.

### Residual

The difference between an observed value and the value predicted by a model.
Residual plots are the quickest check of model assumptions. See
[Linear model](topic:linear-model).

### Standard deviation

The square root of the variance: a measure of spread on the same scale as the
variable.

### Sum of squares

The sum of squared deviations used by analysis of variance and regression. See
[One-way ANOVA](topic:one-way-anova).

### Test statistic

A number computed from the data whose distribution under the null hypothesis is
known or approximated. It is compared with a critical value or converted to a
p-value.

## R terms

### Data frame

R's table-like object with named columns that can have different types. The
active data set is always a data frame.

### Formula

The `response ~ predictors` syntax used by models and plots. See
[Linear model](topic:linear-model).

### Package

A collection of R functions and data. A dialog that needs a package reports it
as unavailable until the package is installed. See
[Loading packages](topic:loadPackages).

### Workspace

The R objects in the current session. Saving a workspace is not the same as
saving a report or a script; the command log and the script are the reproducible
artefacts.
