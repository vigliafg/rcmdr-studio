# Diari di handoff

Un file per ogni ondata completata, creato prima della compattazione del
contesto.

## Nomi

```text
wave-00-foundations.md
wave-01-data-studio.md
wave-02-chart-studio.md
wave-03-report-studio.md
wave-04-workbench.md
wave-05-navigation-dialogs-workflows.md
wave-06-help-i18n-onboarding.md
wave-07-platform-plugins-quality.md
```

## Regole

- Usare [`TEMPLATE.md`](TEMPLATE.md).
- Scrivere il diario **prima** che l'utente compatti il contesto.
- Committare e pushare il diario.
- Il diario è la fonte di verità per la sessione successiva.
- Se una decisione o un problema non è nel diario, non è successo.
